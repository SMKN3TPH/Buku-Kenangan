## Tentang

Website buku kenangan digital untuk angkatan 2026 SMK Negeri 3 Tapung Hulu. Dibangun sebagai static site dengan Supabase sebagai backend.

## Fitur

- 📋 **Arsip Angkatan** — Daftar 68 siswa dengan filter jurusan & inisial
- 🖼️ **Galeri Kenangan** — Dokumentasi resmi + kiriman teman-teman
- 💬 **Pesan Kenangan** — Tulis dan baca pesan dari seluruh angkatan
- 📚 **Pustaka** — Info sekolah, wali kelas, dan kontak

## Tech Stack

- **Frontend**: Vanilla HTML, CSS, JavaScript
- **Backend**: [Supabase](https://supabase.com)
- **Hosting**: [Vercel](https://vercel.com)

## Struktur

```
├── index.html       # Sampul
├── pembuka.html     # Narasi pembuka
├── angkatan.html    # Daftar siswa
├── galeri.html      # Galeri foto
├── pesan.html       # Pesan kenangan
├── pustaka.html     # Info sekolah
├── style.css        # Semua styling
├── utils.js         # Helper & konstanta
├── config.js        # Konfigurasi Supabase
├── supabase.js      # Query database
├── galeri.js        # Logic galeri
├── pesan.js         # Logic pesan
└── user-memory.js   # Profil pengguna
```
